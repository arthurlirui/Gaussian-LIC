\subsection{Election State Machine}

Each node is in one of three states: \textsc{follower}, \textsc{candidate},
\textsc{head}. On head heartbeat timeout (3~s), a \textsc{follower} becomes
\textsc{candidate} and broadcasts ELECTION. If its score is highest, it
becomes \textsc{head}. A higher-scoring HELLO\_HEAD causes immediate demotion
to \textsc{follower}.

\subsection{Submap Transfer FSM (Sender)}

States: \textsc{idle} $\to$ \textsc{tx\_active} (chunks being sent under
leaky bucket) $\to$ \textsc{wait\_ack}. On SUBMAP\_ACK: $\to$ \textsc{idle}.
On SUBMAP\_NACK: re-send missing chunks up to 3 times; on 3rd failure,
mark submap failed and notify application to re-extract at higher
compression.

\subsection{Connection Lifecycle}

\begin{enumerate}
  \item \textbf{Discovery} (0--500~ms): HELLO broadcast; replies from peers
    and head.
  \item \textbf{Calibration handshake} (0--2~s): head sends coarse
    $T_{W_h\leftarrow W_i}$ prior; refined after first submap exchange.
  \item \textbf{Steady state} (indefinite): POSE\_STREAM (20~Hz),
    SUBMAP\_PUSH (on boundaries), KEYFRAME (1~Hz), MAP\_DELTA (1~Hz).
  \item \textbf{Autonomous mode} (on link loss $>$3~s): buffer submaps;
    re-broadcast HELLO every 1~s; flush on reconnect.
  \item \textbf{Leave}: send LEAVE; head marks submaps as
    owned-but-absent for $T_{\text{keep}}=60$~s, then garbage collected
    unless loop-constrained.
\end{enumerate}

\subsection{Map Consistency Guarantees}

\begin{itemize}
  \item \textbf{Monotonic versions}: MAP\_DELTA carries sequential version
    numbers; members apply only if local version matches.
  \item \textbf{Submap idempotency}: globally unique IDs prevent duplicate
    merge.
  \item \textbf{PGO convergence}: iSAM2 incrementally updates the graph;
    rigid per-submap correction preserves internal geometry.
  \item \textbf{Orphan timeout}: absent-node submaps kept 60~s; preserved
    if loop-constrained.
\end{itemize}
