% ============================================
% Section: Cooperative Pose-Graph SLAM Backend
% ============================================
\label{sec:mapping}

The cooperative mapping back-end reconciles per-node local Gaussian maps
into a globally consistent photo-realistic map through registration, merge,
pose-graph optimization, and loop closure. These components receive submaps
from the communication layer; their cost feeds into the latency budget.

\subsection{Local Map and Ownership}

\label{sec:local}

Each node's local map $\GaussianMap_i$ is identical to Gaussian-LIC2's: a
3DGS map densified by a zero-shot depth completer for LiDAR-blind areas,
supervised by LiDAR geometry and camera photometry~\cite{lang2026gaussian2}.
The sole extension is an \textbf{owner} tag ($\text{node\_id}$) per Gaussian,
enabling per-node pruning and confidence weighting.

\subsection{Inter-Node Submap Registration}

\label{sec:registration}

When the head receives submap $\submap_j$ (expressed in $W_j$), it estimates
the aligning transform $T_{W_h\leftarrow W_j}$ via three cascaded strategies:

\paragraph{(1) Coarse prior.} GNSS fix, prior map anchor, or initial handshake
seeds the optimization with $10\times$ inflated covariance.

\paragraph{(2) Gaussian-to-Gaussian ICP.} Incoming Gaussian means are registered
against the head's merged map using weighted point-to-plane ICP. The planarity
score $\kappa_g=(\lambda_2-\lambda_1)/\lambda_2$ (from scale covariance
eigenvalues) weights each correspondence by $\alpha_i\alpha_j\kappa_i\kappa_j$.
Converges within $\sim$10 iterations at $>$30\% spatial overlap.

\paragraph{(3) Visual feature fallback.} When overlap is below 30\%, SuperPoint
+ LightGlue matches between stored keyframe descriptors recover the pose via
PnP+RANSAC, refined by step~(2). The output is an inter-node factor with
information matrix from the ICP Hessian.

\subsection{Gaussian Map Merge}

\label{sec:merge}

Aligned Gaussians are merged by spatial deduplication (octree query within
$\tau_d=3\bar{s}$, fusing overlapping pairs by opacity-weighted averaging
of means, scales, and SH coefficients) and ownership bookkeeping (merged
Gaussians carry lists of contributing node IDs). The head broadcasts MAP\_DELTA
containing only new and fused Gaussians, enabling lazy member-side updates.

\subsection{Pose-Graph Optimization}

\label{sec:pgo}

A factor graph holds per-node keyframe vertices and three edge types:
intra-node odometry (from CT Gauss-Newton Hessian), inter-node registration
(Section~\ref{sec:registration}), and loop closure
(Section~\ref{sec:loop}). iSAM2~\cite{gtsam_mob} runs incrementally on the
cluster head (10--50~ms per solve on RTX~4090) and at coarser granularity on
the Tier-0 server. Corrections are pushed as MAP\_DELTA pose updates; member
nodes apply rigid per-submap corrections to owned Gaussians.

\subsection{Loop Closure}

\label{sec:loop}

Two complementary mechanisms detect loops: \textbf{geometric}---submap
registration against graph-distant submaps (topological distance $>$5 edges,
10\% overlap threshold); and \textbf{visual}---NetVLAD~\cite{arandjelovic2016netvlad}
keyframe descriptors maintained in a DBoW2-style inverted index, queried at
cosine-similarity $>$0.85. Verified matches add PGO factors with match-inlier
covariance.

\subsection{Conflict Resolution}

\label{sec:conflict}

When two nodes produce divergent parameters for the same spatial region,
conflicts resolve by confidence-weighted voting:

\begin{equation}
  C(g)=\alpha_g\,(n_{\text{photo}}(g)+n_{\text{lidar}}(g))\,w_{\text{sensor}}(\text{owner}(g)),
\end{equation}
where $n_{\text{photo}}$, $n_{\text{lidar}}$ are observation counts and
$w_{\text{sensor}}$ is the per-node quality weight from the node descriptor.
High-confidence Gaussians dominate; low-confidence ones are demoted (50\%
opacity shrink per cycle) and pruned after 3 cycles.

\begin{algorithm}[t]
\caption{Cooperative mapping loop (head-side, per received submap).}
\label{alg:coop}
\begin{algorithmic}[1]
\State Receive SUBMAP\_PUSH $\submap_j$; verify CRC32.
\State Estimate $T_{W_h\leftarrow W_j}$ via Sec.~\ref{sec:registration}.
\State Transform $\submap_j$ Gaussians into $W_h$.
\For{each Gaussian $g\in\submap_j$}
  \State Dedup + fuse or insert per Sec.~\ref{sec:merge}.
\EndFor
\State Add inter-node factor $(T_{W_h\leftarrow W_j},\Omega)$; run iSAM2.
\State Query loop candidates (Sec.~\ref{sec:loop}); add factors if found.
\State Pack new+fused Gaussians into MAP\_DELTA; broadcast to members.
\If{Tier-0 present} \State Push merged submap summary to server. \EndIf
\end{algorithmic}
\end{algorithm}
