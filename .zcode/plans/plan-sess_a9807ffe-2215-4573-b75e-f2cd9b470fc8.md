# Plan: Windows Offline Multi-Modal Gaussian Splatting Framework + Paper Draft

## Overview

Refactor the existing ROS-dependent Gaussian-LIC2 mapping node into a **standalone Windows-compatible offline processing framework** that fuses LiDAR point clouds, iToF/stereo depth, and IMU data for high-quality Gaussian Splatting reconstruction. The original ROS code in `src/` is preserved untouched; all new code goes into a new `win_lic/` directory. A LaTeX paper draft describing the framework design goes into `latex/win_lic_paper/`.

### A2. Key Architectural Changes (ROS → Standalone)

| Original (ROS) | New (Windows Offline) |
|---|---|
| `ros::Subscriber` callbacks feeding 4 queues | `DatasetReader` loads files from disk, feeds `DataAligner` |
| `sensor_msgs::PointCloud2ConstPtr` | `SensorFrame` struct with raw `std::vector<float>` points + colors |
| `sensor_msgs::ImageConstPtr` + `cv_bridge::toCvCopy` | `cv::Mat` loaded directly via `cv::imread()` / depth reader |
| `geometry_msgs::PoseStampedConstPtr` | `CameraPose` struct (Eigen quaternion + translation + timestamp) |
| `pcl::fromROSMsg` | Direct PLY/PCD read via `tinyply` or OpenCV |
| `ros::package::getPath()` | Config-driven `base_path` from YAML |
| `ros::Time::now()` for timeout | `std::chrono` + frame-count-based exit |
| `catkin` build | Pure CMake `add_executable` + `find_package` (no catkin) |
| `termios.h` / `unistd.h` (POSIX-only) | Removed; replaced with `std::cin` polling or auto-exit on file exhaustion |

### A3. Pluggable Sensor Interface (`ISensorSource`)

```cpp
class ISensorSource {
public:
    virtual ~ISensorSource() = default;
    virtual bool open(const YAML::Node& config) = 0;
    virtual bool hasNext() = 0;
    virtual SensorFrame nextFrame() = 0;
    virtual void close() = 0;
};
```

Two implementations:
1. **`DatasetReader`** — reads from disk: images (`*.png/jpg`), depth (`*.exr/png float`), point clouds (`*.ply`), poses (`trajectory.txt` in TUM/KITTI format), IMU (`imu.csv`). This is the primary path for offline processing.
2. **`OrbbecSource`** — stub that compiles behind `#ifdef USE_ORBBEC_SDK`. Provides the interface for live Orbbec Femto Mega / Gemini 3D cameras (LiDAR + iToF + stereo + IMU). Without the SDK installed, it compiles as a no-op with a clear error message at runtime.

### A4. Multi-Modal Depth Fusion (`depth/depth_fusion`)

New fusion module that combines:
- **LiDAR point cloud** → sparse depth map via projection (existing logic in `Dataset::addFrame`)
- **iToF depth** → dense but noisy depth map
- **Stereo disparity** → Semi-Global Matching (SGM) via OpenCV's `cv::StereoSGBM`

Fusion strategy: confidence-weighted combination. LiDAR = high confidence (sparse), iToF = medium (dense, noisy near edges), stereo = medium (texture-dependent). The fused depth map feeds into the existing `DepthCompleter` (SPNet TensorRT engine) for completion.

### A5. CMake for Windows

```cmake
cmake_minimum_required(VERSION 3.18)

# MSVC flags: /O2 /W3, no -pthread (use std::thread)

# No catkin, no roscpp, no pcl_ros, no cv_bridge, no tf
# CUDA arch: auto-detect or let user set -DGAUSSIAN_LIC_CUDA_ARCH=89
```

### A8. Files Ported with Modifications

| File | Changes |
|---|---|
| `src/gaussian.h` → `win_lic/gaussians/gaussian_model.h` | Remove `#include "mapping.h"`, replace `Frame` with new `AlignedFrame`, remove `ros::package::getPath` in Params |
| `src/gaussian.cpp` → `win_lic/gaussians/gaussian_model.cpp` | Remove `tf/quaternionMsgToEigen`, `cv_bridge::toCvCopy`, `pcl::fromROSMsg`. Use direct `cv::Mat` + Eigen + tinyply. Core algorithm (initialize, extend, optimize, densificationPostfix, saveMap, evaluateVisualQuality) preserved. |
| `src/mapping.h` → `win_lic/core/types.h` + `params.h` | Split: `Params` class → `params.h` (no `ros::package`), `Frame` struct → `types.h` (ROS msg types → plain structs) |
| `src/mapping.cpp` → `win_lic/core/pipeline.cpp` + `main.cpp` | Remove `ros::init`, `ros::spin`, subscriber callbacks. Replace with `DatasetReader` → `DataAligner` → `Pipeline::run()` loop. Remove POSIX-only `termios.h`/`unistd.h`/`fcntl.h`. |
